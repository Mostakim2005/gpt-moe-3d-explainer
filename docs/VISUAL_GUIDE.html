[DECISION: Kitten-TTS-JS-Vite-ESM-Shim] DECIDED BY: AGENT - Approved by Human
1-Line Summary: Pre-bundled jszip via Vite optimizeDeps to prevent silent web worker crashes during neural voice loading.

Why We Pivoted: jszip's browser entry point is a UMD bundle with no default ESM export. While the main app received a Vite CJS-to-ESM shim, the worker module graph did not, crashing silently on startup. Adding it to optimizeDeps fixed worker resolution.

[DECISION: Mathematically-Consistent-Logits-Distribution] DECIDED BY: AGENT - Approved by Human
1-Line Summary: Normalized all displayed logits so their softmax distribution sums exactly to 1.000000 at temperature T=1.

Why We Pivoted: Initial heuristic values totaled 1.24, mathematically contradicting probability theory. We aligned all numbers with GPT-2 small ground truth and normalized the values with a residual tail to total 1.000000.

[DECISION: Anchor-Aware-Screen-Space-Caption-Clearance] DECIDED BY: AGENT - Approved by Human
1-Line Summary: Replaced in-canvas 3D text with dynamic screen-space DOM candidate scoring to eliminate geometry collisions.

Why We Pivoted: In-canvas 3D text scaled and skewed with perspective, colliding with active meshes. Projected 2D HTML captions score clearance against all pins, achieving 0 overlaps and 0 out-of-bounds.

[TRAP: Single-Thread-WASM-Override] DO NOT TOUCH
Strict Rule: Never remove the single-threaded WASM override in kitten.worker.ts, or neural voice downloads from HuggingFace will fail.

What Breaks If You Touch It: Multi-threaded WebAssembly requires COOP/COEP headers, which block asset downloads from external CDNs like HuggingFace. Pinning hardwareConcurrency to 1 ensures reliable loading.

Protected Anchor: src/tts/kitten.worker.ts → withSingleThread
[TRAP: Windows-Dev-Server-File-Locking] DO NOT TOUCH
Strict Rule: Always terminate running dev server processes before executing large file operations on Windows.

What Breaks If You Touch It: The Vite file watcher locks open file handles on Windows. Bulk file writes or renames during dev server operation cause fatal ReplaceFileW EIO filesystem errors.

Protected Anchor: start-server.bat | stop-server.bat
[TRAP: Scene-Data-Export-Separation] DO NOT TOUCH
Strict Rule: Never export numerical arrays or constants from scene component files like GptScene.tsx.

What Breaks If You Touch It: Exporting data constants from component files breaks Vite React Fast Refresh, forcing full browser page reloads on every edit and resetting the user's progress.

Protected Anchor: src/scenes/gptData.ts | src/scenes/moeData.ts
